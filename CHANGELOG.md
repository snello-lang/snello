# Changelog

Every release of Snello, newest first, each in a file of its own under [`changelogs/`](changelogs/) in the form of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/): what was added, fixed, changed and removed, and first what a program may need changing for. Versions are [Semantic Versioning 2.0](https://semver.org/spec/v2.0.0.html); until 1.0.0 a minor release may change anything, and the release's file says what. A release's file is written from the commits by `release/changelog.sh` and is the release's notes on GitHub.

- [0.1.0-alpha.1](changelogs/0.1.0-alpha.1.md) - 2026-11-21
