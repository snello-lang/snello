# Teak brand assets

The mark is a teak leaf with the letter T carved out of it: the vertical cut is
the leaf's midrib, the horizontal cut is a vein, and the tip above the cut is the
leaf's own tip. The wordmark is a rounded monoline "teak" whose t repeats the
same two strokes.

| File | Use |
|---|---|
| `mark.svg` | The leaf alone, in teak honey. Works on light and dark backgrounds. |
| `mark-mono.svg` | Same shape, inherits `currentColor`. For toolbars, docs, status bars. |
| `favicon.svg` | Copy of `mark.svg` for browser tabs. |
| `avatar.svg`, `avatar.png` | The mark on a charcoal tile, 1024 px. Upload the PNG as the GitHub organization avatar and for social profiles. GitHub takes PNG, JPG or GIF only, under 1 MB. |
| `logo-light.svg` | Horizontal lockup for light backgrounds. |
| `logo-dark.svg` | Horizontal lockup for dark backgrounds. |
| `wordmark-light.svg`, `wordmark-dark.svg` | The word alone. |

## Colors

| Token | Hex | Role |
|---|---|---|
| Teak honey | `#C68A3A` | The mark, accents |
| Heartwood | `#3B2A1A` | Wordmark and text on light |
| Sapwood | `#F3E9D8` | Wordmark and text on dark |
| Cream | `#F7F1E6` | Light background |
| Charcoal | `#1C1915` | Dark background |
| Leaf green | `#2F7A57` | Secondary accent, used sparingly |

## Rules

- Keep clear space around the mark equal to the width of the T's stem cut.
- Do not recolor the honey mark except to the mono version.
- Minimum size for the lockup is 24 px tall. Below that, use the mark alone.
