## [0.1.0-alpha.2] - 2026-11-26

### Breaking changes

- **types**: The move and borrow checks run on each function as it evaluates, in order, so the checker refuses programs alpha.1 accepted that, in that order, read memory already freed or moved: a compound assignment whose value changes what its place is reached through, `*r += drained(v)` with `r := mut v[0]`; a call whose receiver is borrowed for the call while an argument changes it; a value moved in the index of a place, `xs[take(s)]`; a borrow carried out of an `if` arm whose variable is dropped first. Each is refused with the message of the rule it breaks, and the program is written so the value is read or moved before what borrows it.
- **test**: `-run` and `-bench` take a name or a part of one, `.`, or the anchored forms `^NAME$`, `^(A|B)$` and `^$`, and refuse any other pattern holding a regular expression's characters, `Test.*` among them, before any test runs, so that a pattern keeps its meaning once the language has regular expressions.

### Changed

- **types**: The checker takes longer per check than alpha.1's, a quarter to two fifths, since nearly every function's borrows are now decided on its graph; the allocations are at parity, and the time is the next item of the checker's performance

- **runtime**: Bound a spawn's backlog and describe the runtime in its own terms (#199)

- **runtime**: A full ring's half is read in place, off the task's stack
- **llvm**: Return a function's result through one exit block
